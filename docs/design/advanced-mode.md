# Advanced mode design reference

Advanced mode is the terminal's light, feature-rich presentation. The historical visual exploration is preserved in [demo-theme.html](demo-theme.html).

## Reference palette

| Role | Hex | RGB | HSL |
| --- | --- | --- | --- |
| Primary purple | `#7E57C2` | `rgb(126, 87, 194)` | `262deg 47% 55%` |
| Secondary light purple | `#F3E5F5` | `rgb(243, 229, 245)` | `292deg 46% 93%` |
| Status purple | `#9575CD` | `rgb(149, 117, 205)` | — |

The primary color was originally used for prominent account and update actions. The secondary color was used for hover and alternating-row treatments. Current production tokens and component styles remain authoritative when they differ from this historical reference.
